# 03 点「复制恢复命令」会把「撤销」按钮顶掉

Status: resolved

## 现象

端到端测试第 7 步之后找不到「撤销」按钮：浮层从 `done` 态变成了 `info` 态。

## 根因

`client.js` 里完成态的复制按钮成功后 `publish({kind:'info', …})`，
把整条 done 浮层（含 resume 命令、撤销按钮）替换成了 4 秒后自动消失的提示。
用户复制完命令，恰好是最可能想撤销的时刻，反而没得点了。

## 修复

- `client.js`：复制成功不再换态，改为 `publish({ ...state, copied: true })`，
  在 done 浮层里**原地**多显示一行「已复制恢复命令」，3 秒后只把那行去掉。

## 验证

`node test/e2e.mjs` 第 [7] 步新增断言：「复制之后『撤销』按钮仍在」，且第 [8] 步真的点到了撤销并成功删档。
